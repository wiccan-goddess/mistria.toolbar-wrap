# mistria.toolbar-wrap
Real AI: 0

In short:<br>
<p>This mod will hopefully make it to where the toolbar will just wrap to the first slot instead of the next inventory slot. The keybind to switch pages should still work though.</p>

Credits:<br>
    - sopholopho (originally used their code as a base)<br>
    - [DaveyJones](https://www.nexusmods.com/profile/DaveysMods) gave me tips and let me go through the code for their mod<br>
    - [Lyhsayin](https://www.nexusmods.com/profile/Lyhsayin) showed me a good way to implement my function<br>
    - [MOMI](https://github.com/Garethp/Mods-of-Mistria-Installer) the MMAPI documentation really helped<br>

Reason:<br>
<p>"This type of mod already exists!" Yes, yes, it does. However, that was made using generative AI and I personally don't want to use generative AI mods. No discredit to the mod author and I'm not trying to steal their credit or anything like that. I just simply don't like the fact that AI made it. Yes, figuring out how to mod gml files is probably going to be hard but I'm down to struggle if it helps encourage others to make mods without relying on generative AI. Now that's not to say AI doesn't have a place in the modding community because it might help some people understand how a mod was/is made. That still doesn't dismiss the fact that generative AI is BAD for EVERYONE not just artists or content creators.</p>
